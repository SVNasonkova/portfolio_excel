# portfolio_excel
# Анализ продаж продуктовых сетей и клиентской базы (2023-2024)

## О проекте

Интерактивный Excel-дашборд для анализа продаж продуктовых сетей и клиентской базы.  
Проект демонстрирует подход к **self-service аналитике в Excel** и ориентирован на поддержку бизнес- и продуктовых решений в ритейле.

Дашборд позволяет быстро анализировать ключевые метрики, выявлять точки роста и проводить сегментированный анализ без использования SQL и BI-платформ.

## Бизнес-контекст

Ритейл-командам важно:

- отслеживать динамику продаж и выручки;
- сравнивать эффективность магазинов, ассортимента и поставщиков;
- анализировать клиентскую базу и влияние программ лояльности;
- получать ответы на бизнес-вопросы в формате self-service аналитики.

Данный проект решает эти задачи в формате интерактивного Excel-решения.

## Цель проекта

Создать единый аналитический инструмент, который позволяет:

- мониторить ключевые KPI продаж;
- анализировать динамику и структуру выручки;
- выявлять сильные и слабые места в ассортименте и у поставщиков;
- сегментировать клиентов по географии и поведению.

## Ключевые метрики (KPI)

- GMV (Gross Merchandise Value)
- Количество покупок
- Топ-магазин по GMV
- Топ-категория по GMV
- Топ-поставщик по GMV

Все показатели пересчитываются динамически при изменении фильтров.

## Сегментация и фильтры

Поддерживается сквозной анализ по следующим измерениям:

- год / квартал / месяц;
- магазин;
- категория товара;
- поставщик;
- страна;
- программа лояльности.

Фильтры связаны между всеми аналитическими блоками.

## Аналитические блоки

### Sales performance
- динамика GMV во времени;
- сравнение торговых сетей;
- анализ ценовой стратегии.

### Assortment analysis
- GMV по категориям;
- среднее количество товаров в чеке.

### Supplier analysis
- GMV по поставщикам;
- средние цены поставщиков внутри категорий.

### Customer analytics
- география клиентов;
- давность регистрации;
- анализ customer lifetime;
- платежеспособность по странам;
- частотность имён (пример маркетинговой сегментации).

## Практическая ценность проекта

Дашборд может использоваться для:

- выявления ключевых категорий и поставщиков, формирующих выручку;
- поиска регионов с недоиспользованным потенциалом;
- оценки влияния программ лояльности;
- поддержки решений по ассортименту, ценообразованию и маркетингу.

## Используемые инструменты
