Проект демонстрирует навыки работы с бизнес-метриками, сводными таблицами, срезами и построения связанной аналитики.

👉 **[Скачать Excel-файл с интерактивным дашбордом](https://github.com/SVNasonkova/portfolio_excel/blob/52d672e0ff84c289742e800125e4a4aec2d6655f/retail_sales_analytics/retail-sales_analytics.xlsx)**

---

## 🎯 Цель проекта

Построить единый дашборд для анализа продаж и поведения клиентов с возможностью:
- отслеживать ключевые показатели (GMV, количество покупок);
- анализировать динамику продаж во времени;
- сравнивать магазины, категории товаров и поставщиков;
- оценивать влияние географии и программы лояльности.

---

## 📊 Ключевые показатели (KPI)

- **GMV (Gross Merchandise Value)**
- **Количество покупок**
- **Топ-магазин по GMV**
- **Топ-категория по GMV**
- **Топ-поставщик по GMV**

Все показатели динамически пересчитываются при изменении фильтров.

---

## 🔎 Интерактивные фильтры

В дашборде реализованы следующие срезы:

- Год / квартал / месяц
- Магазин
- Категория товара
- Поставщик
- Страна
- Программа лояльности

Фильтры связаны между аналитическими блоками и позволяют выполнять сквозной анализ.

---

## 📈 Основные аналитические блоки

### Анализ продаж
- Динамика GMV во времени
- Сравнение торговых сетей
- Анализ ценовой стратегии

### Анализ ассортимента
- GMV по категориям
- Среднее количество товаров в покупке

### Анализ поставщиков
- GMV по поставщикам
- Средние цены по поставщикам внутри категорий


### Клиентская аналитика
- География клиентов
- Дни с момента регистрации
- Анализ лайфтайма
- Платежеспособность по странам
- Частотность имен для рекламной компании
